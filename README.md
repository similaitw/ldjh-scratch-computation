# 算衍修仙錄：積木計算篇（宜蘭競賽 Blockly 版）

給國中生的積木計算練習網站，以 RPG 闖關方式準備「宜蘭縣資訊科技創意實作競賽」（個人賽）。

- 修煉室的積木和[競賽平台](https://ilanictexam.pages.dev/)一模一樣，也能切換「Scratch」「Blockly」兩種模式（切換時輸入輸出積木自動轉換，Scratch 模式會把積木包進綠旗）：Google Blockly，工具箱分類、積木種類、讀取數字／讀取文字、說出都相同
- 執行與評分照平台規則：輸入以空白、換行或逗號分隔，每個「讀取」依序取一筆；所有「說出」用空白接起來，逐項比對（3 與 3.0 視為相同）；超過 3 秒判定執行超時
- 可「下載 XML」，到比賽平台按「上傳 XML」載入同一份積木
- 每一區附「競賽對照」：平台上同觀念的宜蘭縣賽、全國賽題目
- 兩個世界觀可切換：仙俠修仙（算衍修仙錄）、西洋魔法學院（星輝魔法學院），題目與進度共用
- 3D 浮空島地圖（three.js）
- 配樂與音效用 Web Audio 即時合成（仙俠：五聲音階古箏與笛；魔法學院：鐘琴琶音），沒有音樂檔，右上角「♪ 音樂」可關閉
- 九區 55 題全部開放：收銀（變數、餘數）、收費（條件）、存錢（迴圈）、藏經閣（讀 N 筆資料統計）、演武場（清單、排序）、靈舟渡口（文字處理）、宗門大比（迴圈裡的迴圈，對應縣賽）、天機閣（因數、質數、最大公因數）、問道峰（N×N 方陣）
- 每關都有「⚡ 快速解答」：一鍵把參考答案放進積木區；寫完修行心得就自動突破境界

## 檔案

- `index.html`：整個網站
- `lib/blockly/`：Google Blockly 12.5（Apache-2.0）與繁體中文語系
- `lib/forge.js`：修煉室（競賽版工具箱、執行、評分）
- `lib/music.js`：配樂與音效
- `lib/bdsl.js`：把引導步驟的積木文字轉成 Blockly 積木（積木圖與參考程式共用）

純靜態網站，不需要建置步驟。進度存在學生自己的瀏覽器（localStorage），可用「存檔」下載存檔檔案。
